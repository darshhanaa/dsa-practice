# Largest Element in Array

## Problem
Given an array of integers, find the largest element.

### Example
Input:
[3, 7, 2, 9, 5]

Output:
9

## Approach
- Assume the first element is the largest.
- Traverse the array.
- Update the largest value whenever a bigger element is found.

## Time Complexity
O(n)

## Space Complexity
O(1)
